# Change Log

## [0.3.0] - 2026-10-14
- Add `changelog.dayOfWeekLang: "none"` to insert headline without weekday
- Add Outline integration for ChangeLog sections and items
- Add file name completion for GNU-style `* filename` entries
- Add token completion for `* filename(token` entries
- Add go-to-definition support for filename/token references in bullet entries
- Update dependencies:
  - `dayjs` to `^1.11.23`
  - `@types/vscode` to `^1.140.0`
  - `eslint` to `^8.57.1`

## [0.2.0] - 2023-07-10
- Add placeholder to snippet. 
  - from `* {tag}:` to `* {tag}:{statement}`
- Update dependencies

## [0.1.0] - 2020-04-04
- Support "ChangeLog" as file extension i.e. `foo.ChangeLog`

## [0.0.3] - 2018-12-15
